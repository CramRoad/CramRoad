# CramRoad Study — JEE + NEET (GitHub Pages ready)

Free chapter-wise JEE (Main+Advanced) + NEET UG tutorials, practice tests and PYQs. Pure static site — no build, no backend.

## What's inside
- `index.html` → JEE home (subjects + routine + drill quiz)
- `neet.html` → NEET UG home (subjects + routine + drill + PYQ year index)
- 11 tutorial pages: Maths, JEE Physics, NEET Physics, Physical / Organic / NEET Organic / Inorganic / NEET Inorganic / NEET Physical Chemistry, Botany, Zoology
- `practice/` → 101 chapter-wise 25-question test pages (Botany 23, Zoology 16, Organic 8, Physics 25, Inorganic 20, Physical 9)
- `pyq/` → 10 year-wise PYQ test pages (2017–2026, 180 questions each)
- `about.html`, `contact.html`, `privacy.html`, `terms.html`
- `logo.svg`, `favicon.svg`, `favicon.png`, `apple-touch-icon.png`, `.nojekyll`

## Host on GitHub Pages (2 min)
1. Create a new public repo on GitHub, e.g. `cramroad-study`
2. Upload ALL files and folders from this folder to the repo root
   (keep the same structure: `practice/` and `pyq/` stay as subfolders)
3. Repo → Settings → Pages → Deploy from branch → `main` / `(root)` → Save
4. Open `https://YOUR-USERNAME.github.io/cramroad-study/` (JEE)
   and `.../neet.html` (NEET)

No build step. Progress in quizzes is session-only; tutorial planner data (where present) uses `localStorage`.
